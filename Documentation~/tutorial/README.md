# Tutorial: SIMPLE Unity Plugin With GAMA

This tutorial is the main learning path for using the SIMPLE Unity Plugin with
GAMA through `simple.webplatform`.

The goal is to start from an empty Unity scene, run a live GAMA experiment in
Play Mode, then introduce the Unity Editor preview as a faster way to inspect
and tune the scene before running the live simulation again.

## Tutorial Flow

0. [Prepare the middleware and the GAMA experiment.](https://github.com/project-SIMPLE/SIMPLE-Unity-Plugin/blob/main/Documentation~/tutorial/00-gama-model-preparation.md)
1. [Install the Unity package.](https://github.com/project-SIMPLE/SIMPLE-Unity-Plugin/blob/main/Documentation~/tutorial/01-installation-and-setup.md)
2. [Run the GAMA experiment in Unity Play Mode.](https://github.com/project-SIMPLE/SIMPLE-Unity-Plugin/blob/main/Documentation~/tutorial/02-first-experiment-launching.md)
3. [Personalize agents during Play Mode.](https://github.com/project-SIMPLE/SIMPLE-Unity-Plugin/blob/main/Documentation~/tutorial/03-personalization.md)
4. [Generate and configure an Editor preview.](https://github.com/project-SIMPLE/SIMPLE-Unity-Plugin/blob/main/Documentation~/tutorial/04-generate-preview.md)
5. [Drive dynamic visual properties from GAMA runtime attributes.](https://github.com/project-SIMPLE/SIMPLE-Unity-Plugin/blob/main/Documentation~/tutorial/05-dynamic-colors.md)
## Before You Start

You need:

- Unity 6000.3.2f1;
- GAMA;
- `simple.webplatform` on branch **dev** using : `git clone -b dev --single-branch https://github.com/project-SIMPLE/simple.webplatform.git`;
